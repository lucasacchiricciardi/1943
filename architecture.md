# architecture.md

Questo file documenta le scelte architetturali principali del progetto "Clone 1943". Ogni decisione qui riportata serve a garantire coerenza e tracciabilità durante lo sviluppo.

## Linee guida
- Ogni modifica architetturale va discussa e documentata qui prima di essere implementata.
- Le dipendenze principali, la struttura delle cartelle, i pattern di progettazione e le convenzioni di modularizzazione devono essere esplicitate.

## Scelte attuali
- Utilizzo di JavaScript ES Modules per la separazione delle logiche di gioco.
- Struttura a cartelle per separare entità (player, enemies, bullets, ecc.).
- TDD e documentazione continua.
- Convenzioni di commit: Conventional Commits.

_Aggiornare questo file ad ogni decisione architetturale rilevante._
