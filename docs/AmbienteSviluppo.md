# Ambiente di Sviluppo – Clone 1943

## Requisiti
- Node.js (consigliato per gestione test e strumenti)
- Editor: Visual Studio Code o equivalente
- Browser moderno (Chrome, Firefox, Edge, Safari)

## Struttura del progetto
- `src/` — Codice sorgente (HTML, CSS, JS)
- `assets/` — Immagini e audio
- `tests/` — Test automatici
- `docs/` — Documentazione

## Convenzioni
- Branch principale di sviluppo: `develop`
- Branch stabile: `main`
- Commit secondo [Conventional Commits](https://www.conventionalcommits.org/it/v1.0.0/)
- Versionamento semantico (semver)

## Strumenti consigliati
- VS Code Extensions: Prettier, ESLint, Live Server
- Gestione test: Jest o simile (per TDD)
- Gestione immagini/audio: strumenti open source

## Avvio rapido
1. Clona il repository
2. Lavora sulla branch `develop`
3. Avvia Live Server su `src/index.html` per sviluppo rapido
4. Esegui i test con il comando dedicato (da configurare)

---

Per dettagli e procedure aggiornate, consulta la documentazione in `docs/`.
