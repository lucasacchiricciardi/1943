## Convenzioni di Versionamento e Branching

- Verrà adottato il sistema di commit [Conventional Commits](https://www.conventionalcommits.org/it/v1.0.0/), per garantire chiarezza e tracciabilità nella storia del repository.
- Lo sviluppo avverrà principalmente sulla branch `develop`.
- Al termine dello sviluppo e dopo la validazione, il software verrà versionato semanticamente e il codice stabile sarà portato nella branch `main`.

Vedi il file originale nella root. Spostare qui il PRD per mantenere ordine nella documentazione.
